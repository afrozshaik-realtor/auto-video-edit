# Roadmap

## Phase 2 (next)
- Settings: businesses (name, colour, style rules editor), tags (rename, merge,
  colour), tools list, team members list for the assignee picker, app version and changelog.
- Library: every prompt and director note in one place for quick copying.
- Activity history on the reel detail screen.
- Filters saved in the URL so a filtered board can be bookmarked or shared.
- Dark mode polish.
- Migrations framework (`src/data/migrations.ts`), keyed by `schema_version` in the
  `Meta` tab, run on load by the first person with edit access.
- More tests for workflow logic.

## Future ideas (not planned yet)
- Canva: auto-generate a cover or thumbnail from a brand template (Canva Connect API).
- Content calendar view and posting schedule per business.
- Notifications to the assignee (Zapier, email or WhatsApp).
- Performance tracking (views, saves) entered after posting.
- AI caption and hashtag generator inside the app (needs a backend to hold API keys).
- Odoo CRM link for leads generated by a reel.
